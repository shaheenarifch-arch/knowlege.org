# Knowlege.org Portal

Global knowledge, Qur'anic learning, research, charity and help portal.

## Run
```powershell
npm install
npm run typecheck
npm run dev
```
Open `http://localhost:3000`.

## Generate draft content
```powershell
npm run content:daily
npm run newsletter:build
```
All automated content remains `DRAFT` and requires source review.

## GitHub repository name
`knowlege-org-portal`

## Production reminder
The starter contains no copyrighted Qur'an editions, translations, tafsir, hadith, recitation audio or videos. Verify rights before importing content. Do not take donations before legal, financial, safeguarding and compliance controls are established.
