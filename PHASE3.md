# Knowlege.org Phase 3

Adds Abdul AI as a voice and text learning companion with:
- Illustrated non-photorealistic avatar
- Browser voice input and speech output
- Learn, Research, Reflect, Study and Serve modes
- Source-only retrieval interface
- RAMBO integration behind an explicit feature flag
- Citation validation
- Personal-ruling and crisis referrals
- Session/message schema
- Safety tests

The retrieval adapter intentionally returns no content until reviewed datasets are connected. This prevents an apparently functional assistant from fabricating religious sources.
